05 Local Connection and Saved Settings

The Figma plug-in checks whether the Nythxion Watermarker desktop application is installed on your PC. If it is, the plug-in reads the Watermarker save data, including the main save slot. The save slot stores the settings you choose for watermarking, such as the content you want to watermark, the watermark colour, and rotation.

The plug-in and the desktop application exchange this information through http://localhost:51820, and the desktop application communicates with the plug-in in the same way. This communication takes place on your device and is not sent to Nythxion Studios servers. The desktop application must be installed for the plug-in to work if the desktop application is not running, then no information is fetched.

You must not modify this connection, expose it to other devices or networks, or use it with software other than the official plug-in and desktop application. Nythxion Studios is not responsible for the security of a local connection that you have changed or exposed.

11 Data Processed by Nythxion AI

Depending on which features are used and how a server is configured, Nythxion AI may process the following information:

  • Discord User IDs
  • Discord Server IDs
  • Discord channel IDs where required for configuration
  • Usernames or Discord tags where required for moderation records

  • Messages or prompts submitted through AI commands
  • User-saved memory created through memory features
  • Leveling and economy information
  • Moderation information such as warnings, timeouts, kicks, and bans

12 AI Processing

When an AI command is used, the relevant prompt or content may be transmitted to an external AI provider, currently Groq, to generate the requested response.

Nythxion AI also uses Groq's AI models for AI-assisted moderation. The moderation system first checks messages locally. If a message triggers the local moderation filter, the message content may then be sent to the AI moderation system for contextual analysis.

Not every Discord message is sent to Groq. Messages that do not trigger the applicable AI moderation filter are not sent to Groq through this moderation process.

13 AI Moderation Data

When a message triggers AI-assisted moderation, the relevant message content may be transmitted to Groq together with the information necessary for the AI model to perform the classification.

The AI moderation system may evaluate categories including profanity, harassment, slurs, sexual content, threats, and abusive language.

The resulting moderation decision may be used to automatically perform actions such as deleting a message or applying a temporary timeout.

14 Moderation Logs

If a server enables moderation logging, information about moderation actions may be stored or sent to the configured moderation-log channel. This may include information such as the affected user, moderator, action, reason, and timestamp.

Server administrators are responsible for configuring moderation-log features appropriately for their server and should consider their own data-protection obligations.

15 User Memory

If a user explicitly uses a memory feature such as /remember, the information provided through that feature may be stored to provide the requested memory functionality.

Users can request deletion of stored memory and may use available bot commands to remove memory where supported.

16 Groq as an External Provider

AI processing is currently provided through the Groq API. Groq states that customer data for inference requests is not retained by default. However, Groq states that inputs and outputs may be temporarily retained for system reliability or abuse monitoring for up to 30 days unless Zero Data Retention controls apply. Groq also states that retained customer data is stored in the United States.

Accordingly, message content submitted to Groq may be processed outside the European Economic Area. Appropriate information regarding international data transfers and applicable safeguards should be considered when configuring and using the service.

17 Discord

Nythxion AI operates through Discord. Discord independently processes information in connection with its platform and services. Nythxion AI does not control Discord's processing of personal data.

For information about Discord's own data processing, users should consult Discord's current privacy documentation. Discord's Terms of Service and Community Guidelines also apply to your use of Discord.
